# Seguridad y reporte responsable

## Datos

El repositorio usa datos abiertos de contratación pública. RAW y archivos derivados locales no se versionan. No deben añadirse credenciales, cadenas con contraseña, tokens ni datos ajenos al alcance oficial documentado.

## Configuración local

`.env` está excluido de Git. SQL Server usa autenticación integrada de Windows y el código prohíbe bases de sistema como destino.

## Hallazgos

No usar issues públicos para divulgar credenciales o información sensible accidental. Contactar al mantenedor del repositorio de forma privada y describir el archivo, el commit y el impacto sin incluir el secreto completo.

Los indicadores de Supplier Exposure no son acusaciones de irregularidad, fraude, insolvencia ni incumplimiento.
